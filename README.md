# 🚗 Blacklist Detailing

> **Estética y cuidado vehicular profesional en San Rafael, Mendoza.**  
> Landing page comercial diseñada para captación de clientes y reservas directas a través de WhatsApp e Instagram.

---

## 📌 Descripción general

Este proyecto es la página web oficial de **Blacklist Detailing**, un taller especializado en detailing y estética vehicular ubicado en San Rafael, Mendoza, Argentina. 

El sitio fue diseñado con un enfoque "mobile-first", velocidad de carga óptima (sin dependencias pesadas ni frameworks innecesarios), identidad visual oscura y elegante, y botones de llamada a la acción (CTA) directos para coordinar turnos por WhatsApp.

---

## ✨ Características

- ⚡ **Ligero y rápido:** Construido en HTML5 semántico, CSS3 moderno y Vanilla JavaScript.
- 📱 **Diseño 100% Responsivo:** Adaptado para teléfonos celulares, tablets y computadoras de escritorio.
- 💬 **Integración con WhatsApp:** Botón flotante y enlaces directos con mensajes preconfigurados para pedir presupuestos o turnos.
- 🗺️ **Mapa interactivo:** Integración con Google Maps para ubicar fácilmente el taller en Av. Juan B. Alberdi 1271.
- 🔍 **SEO Local & Schema.org:** Metadatos estructurados en formato JSON-LD (`AutoDetailing`) para mejorar el posicionamiento en Google.
- 📸 **Galería de trabajos:** Grilla con soporte para fotografías reales de autos finalizados.

## 🛠️ Servicios Ofrecidos

1. **Lavado de mantenimiento:** Limpieza exterior e interior minuciosa para conservación habitual y embellecimiento de neumáticos.
2. **Lavado premium:** Limpieza profunda con descontaminado, lavado de llantas y aplicación de cera hidrofóbica.
3. **Lavado de interiores:** Aspirado profundo, extracción de manchas en tapizados y eliminación de olores.
4. **Abrillantado:** Pulido en una etapa para retirar micro-rayas y recuperar brillo.
5. **Pulido y corrección de rayas:** Corrección intensiva de pintura para eliminar rayas profundas y hologramas.
6. **Protección cerámica:** Sellador de alto rendimiento con brillo extremo y efecto hidrofóbico duradero.
7. **Reacondicionamiento de ópticas:** Pulido, lijado y protección UV contra el amarilleo solar.
8. **Pintura de llantas:** Reparación estética y repintado profesional.

## 🚀 Cómo usar o previsualizar este proyecto

1. Clona el repositorio o descarga los archivos:
   ```bash
   git clone https://github.com/Ignacio-Helbas/blacklist.git
   ```
2. Abre la carpeta en tu editor de código preferido (ej. VS Code, Antigravity).
3. Abre el archivo `index.html` en tu navegador o utiliza una extensión de servidor local como *Live Server*.
